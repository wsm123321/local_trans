# 源局部区域引导目标候选重排序：实证检验与边界分析报告

## 1. 实验设置与研究定位

本报告基于严格独立的随机数流（SeedSequence 分离）、排他候选池（去除了源数据与已评测点）、正确的并列排名处理（rankdata）与样本外交叉验证增量方差（Out-of-Sample $\Delta R^2_{\mathrm{OOS}}$）。

- **独立控制实例数**：$N = 64$（覆盖 GMM、Rastrigin、Lunacek、Ackley 跨 2D/5D 与独立随机种子）。
- **研究定位**：机制探索原型与局部区域先验有效性边界分析。

## 4. 配对差异与置信区间 (Paired Statistical Inference)

- **Source-Region vs Target-Only**：
  - 归一化 Regret 差值均值：**+0.0734**（95% Bootstrap CI: [+0.0155, +0.1296]）
  - 配对 t 检验 $p = 1.5315e-02$，Wilcoxon 符号秩检验 $p = 1.2186e-02$
  - 胜率统计：胜 **59.4%** / 平 **10.9%** / 负 **29.7%**
- **Source-Region vs Random-Region (结构匹配)**：
  - 归一化 Regret 差值均值：**+0.0879**（95% Bootstrap CI: [+0.0235, +0.1501]）
  - Wilcoxon 符号秩检验 $p = 1.4463e-02$

## 5. 阶段二与阶段三结论摘要

1. **连续空间漂移曲线 (Phase 2 Drift Curve)**：当源区域中心漂移量 $\delta \le 0.5$ 时，源区域保持正向信息增益与 Regret 削减；当 $\delta \ge 1.0$ 时，增量方差迅速收敛至 0，由于软重排序的低方差安全门控机制，方法自动降权保护，避免严重负迁移。
2. **闭环序列优化 (Phase 3 Sequential BO)**：在多步迭代优化中，配合先验动态退火 $\lambda_t = \lambda_0 / (1 + 0.05 t)$，Source-Region 在前中期展现出更快的收敛速度，后期平滑过渡至纯目标模型主导。
